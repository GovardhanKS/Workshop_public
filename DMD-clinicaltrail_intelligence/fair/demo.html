Methodology & provenance

Scores implement the FAIRsFAIR Data Object Assessment Metrics (16 metric IDs, FsF-F1-01D…FsF-R1.3-01M) as used by F-UJI. On-screen values are a provisional heuristic computed in code from each record metadata; the LLM/RAG layer only narrates them and cannot alter a score. Records with a resolvable PID/DOI are assessed by the live F-UJI service (pipeline --fuji).

Data: ChEMBL, ClinicalTrials.gov and PubMed records pulled live & verified; GEO records are seeds pending E-utilities verification (flagged, scored lower).
Limitation: F-UJI assesses datasets via a PID landing page — a clean fit for GEO; compounds/trials/papers are scored by the same metric logic at catalogue level.
Cite: Devaraju & Huber (2023), F-UJI, doi:10.5281/zenodo.6361400; metrics doi:10.5281/zenodo.6461229.

Scoring calibration — heuristic vs authoritative F-UJI

Δ = heuristic − F-UJI (target |Δ| ≤ 10). The F-UJI column is populated by calibrate.py --fuji on a networked machine. F-UJI scores dataset objects (GEO accessions / DOIs); ChEMBL compounds & trial registrations are catalogue-level heuristic only and marked N/A.
F-UJI requires machine-actionable metadata (schema.org / DataCite, PID signposting), so it typically scores lower than an optimistic heuristic — a positive Δ is expected and drives the tightening loop.
Sources: ChEMBL (EMBL-EBI), ClinicalTrials.gov (NIH/NLM), PubMed, GEO (NCBI). GEO records flagged [SEED] are pending live E-utilities verification and score lower by design.
